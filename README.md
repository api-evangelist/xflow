Xflow is a cross-border payments platform for Indian businesses, freelancers, and exporters, enabling them to receive international payments through local collection accounts (ACH in the US, SEPA in the EU) with one-day INR settlement, transparent FX at mid-market rates, and automated FIRA and compliance reporting. The Xflow REST API exposes accounts, receivables, payment links, deposits, payouts, transfers, balances, exchange rates, and webhook endpoints so platforms and payment aggregators can embed compliant India-bound money movement.

**Areas:** Payments · Cross-Border Payments · Fintech · India · Foreign Exchange · Invoicing · Payouts

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Xflow: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
